# AgentKey Pages

This repository contains the two standalone AgentKey page versions:

- `renew/` - the renewed homepage and its local assets.
- `pricing/` - the pricing page and its local assets.

## Run

Open either `renew/index.html` or `pricing/index.html` directly in a browser,
or serve the repository with any static file server. The root `index.html`
redirects to `renew/`.
